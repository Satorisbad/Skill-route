# UI/UX domain

Load for interface design, screenshot recreation, UX review, visual systems, interaction design, and front-end visual implementation.

Also load coding when implementation is required.

## Rules
- Inspect the existing interface before changing it.
- Never invent icons. Use real icons from the chosen icon library; prefer Tabler when applicable.
- If no suitable icon exists, say so and discuss alternatives.
- Use real references/assets where available.
- Do not silently remove working interactions or keyboard shortcuts.
- Test end-to-end workflows, not just isolated screens.
- Check hierarchy, discoverability, cognitive load, accessibility, recovery/undo, and workflow completion.
- For screenshot recreation, compare the rendered result against the reference and iterate.
