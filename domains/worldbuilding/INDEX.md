# Worldbuilding domain

Load for fiction systems, lore, characters, plot, canon, and setting design.

## Rules
- Separate established canon from proposals.
- New explicit user corrections override older canon.
- Do not convert unresolved brainstorming into canon.
- Preserve project terminology exactly.
- Load project-specific canon from a project overlay/reference file rather than bloating this generic domain.
- When writing prose from canon, also load the writing domain.
