# Coding domain

Load this for implementation, debugging, repository changes, refactors, build issues, and technical integration.

## Required behavior
- Inspect repository structure before editing.
- Prefer minimal, targeted changes over unnecessary rewrites.
- Preserve existing functionality unless change is explicitly requested.
- Build/run/test before declaring success.
- When a bug is uncertain, reproduce it before proposing a fix where practical.
- Use existing project conventions, dependencies, and tooling before introducing new ones.
